# Flow CS Hub

수학의아침 CS 직원 통합 상담 지원 플랫폼.

**대상**: CS 직원 전용 (학부모 접근 불가)
**캠퍼스**: 수내 · 이매 · 수지 · 광교 · 영통
**호스팅**: GitHub Pages
**상태**: MVP (Phase A-3 완료)

## 사용법

- URL: https://coayay.github.io/flow-cs-hub/
- 접근 비밀번호는 CS팀 팀장에게 문의

## 기술 스택

- 순수 HTML/CSS/JS (SPA)
- Fuse.js 7.0 (오타 허용 검색)
- Web Crypto API (SHA-256 인증)
- JSON 데이터

## 데이터 갱신

`data/*.json` 파일 편집 후 커밋. GitHub Pages가 자동 배포.

원천 자료 재생성이 필요하면 `build_data.py` 실행 (내부용).
